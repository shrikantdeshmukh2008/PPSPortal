Step by step workflow to create and run the Docker image for your first service (Service Registry):
Step 1: Start Docker Desktop
Make sure Docker Desktop is running (you’ll see the whale icon in your taskbar).

Without this, commands in CMD/PowerShell will fail with “Cannot connect to Docker daemon”.

Step 2: Verify Docker is Active
Run:
	docker --version
	docker ps

Step 3: Build the JAR

Compile your Spring Boot project into a runnable JAR file.

Open Command Prompt → Navigate to config-server folder

Run: mvn clean package -DskipTests

Verify JAR is created in target/ folder

Step 4: Create Dockerfile
Define how Docker should package your service.

Inside config-server folder

Use base image: FROM eclipse-temurin:17-jdk

Copy JAR: COPY target/config-server-0.0.1-SNAPSHOT.jar /usr/app/

Set workdir: WORKDIR /usr/app/

Expose port: EXPOSE 8888

Entrypoint: ENTRYPOINT ["java","-jar","config-server-0.0.1-SNAPSHOT.jar"]

Step 4: Build Docker Image
Convert your JAR + Dockerfile into a Docker image.

Run in Command Prompt

Navigate to config-server folder

Run: docker build -t config-server:latest .

Verify with: docker images

Step 5: Run Docker Container
Start the service inside a Docker container.

Run in Command Prompt

Run: docker run -d -p 8888:8888 config-server

Check running containers: docker ps

Verify Config Server is running and serving configs. at: http://localhost:8888/ff-oms-integration-service/default

Step 6: Push to Docker Hub (Optional)
Share your image publicly if needed.

Run in Command Prompt

Login: docker login

Tag: docker tag config-server:latest your-dockerhub-username/config-server:latest

Push: docker push your-dockerhub-username/config-server:latest

✅ Summary:

Local laptop → build JAR, build image, run container, verify at http://localhost:8888/ff-oms-integration-service/default

Docker Hub → optional, only if you want to share or deploy remotely.
