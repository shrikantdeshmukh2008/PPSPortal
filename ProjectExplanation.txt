Order Lifecycle Microservices Project  
I built a system to manage orders that come from an external storefront portal. The project has four microservices:

Order Service (OMS) to receive and track orders placed externally.

Inventory Service to check product stock and reserve items against those orders.

Fulfillment Service to pack the reserved items and mark them ready.

Shipping Service to assign a courier and tracking number once items are packed.

Each service has its own database and communicates with the others through APIs. The system updates the order step by step — from Placed (by storefront) → Reserved → Packed → Shipped. I also added error handling (like when stock is insufficient), logging to trace the flow, and monitoring with health checks.

For demonstration, I prepared sample inventory data and Postman collections to show the complete order lifecycle. I also created Docker files and Kubernetes manifests to illustrate how the services can run in containers and scale in a real environment.
